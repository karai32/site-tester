# Site Tester

- Рабочая версия: [test.teplyakov.fun](https://test.teplyakov.fun)
- Репозиторий: [github.com/karai32/site-tester](https://github.com/karai32/site-tester)

## Что используется

- Серверная среда: Node.js 22+
- Фреймворк: Fastify
- Проверки: Playwright Test + Chromium
- База данных: SQLite
- Интерфейс: обычный HTML, CSS и JavaScript
- Сервер: Nginx и systemd

Сервис настроен на один сайт. Название и адрес сайта задаются через `SITE_NAME` и `SITE_URL`.

## Как работает проверка

1. Пользователь нажимает кнопку запуска.
2. Fastify создаёт новую проверку.
3. `scanner.js` по очереди запускает файлы из `src/checks/`.
4. Playwright открывает сайт в Chromium и выполняет нужные действия.
5. Результаты и скриншоты сохраняются в SQLite.
6. Интерфейс получает результат через API и показывает его по категориям.

Одновременно может выполняться только одна проверка. По умолчанию в базе хранятся последние 30 запусков.

## Что проверяется

- доступность и безопасность
- навигация, шапка и футер
- поиск, фильтры и пагинация
- контент
- внешний вид и адаптивность
- формы
- виджеты и способы связи
- SEO
- защита и антиспам

Проверки запускаются только в Chromium. Полноценной проверки Safari и Yandex Browser пока нет. Проверки заявок в CRM и ФОС также пока выполняются вручную.

## Основные методы Playwright

- `chromium.launch()` запускает браузер.
- `page.goto()` открывает страницу.
- `page.locator()` ищет элементы по CSS-селекторам.
- `count()`, `isVisible()` и `getAttribute()` проверяют элементы и их атрибуты.
- `click()` и `fill()` нажимают кнопки и заполняют поля.
- `page.evaluate()` выполняет простой JavaScript внутри страницы.
- `context.request.get()` проверяет HTTP-статусы ссылок и изображений.
- `response.securityDetails()` получает информацию об SSL.
- `page.screenshot()` сохраняет подтверждение результата.
- Разные размеры viewport используются для проверки мобильной версии.

## Структура проекта

- `config/` содержит настройки проверяемого сайта.
- `src/server.js` запускает Fastify и API.
- `src/scanner.js` управляет всей проверкой.
- `src/checks/` содержит отдельные проверки по категориям.
- `src/db.js` отвечает за SQLite.
- `public/` содержит интерфейс на HTML, CSS и JavaScript.
- `.github/workflows/` содержит автоматический деплой на сервер.

## Локальный запуск

```bash
npm ci
npm run pw:install
npm run dev
```

После запуска сервис доступен по адресу `http://127.0.0.1:3000`.
